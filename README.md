# Real-Time Bus Tracking & Delay Detection (Kafka + Azure)

## Overview
This project simulates a real-time bus tracking system using Apache Kafka and Azure Event Hubs.

## Architecture
Producer → Kafka (bus-events) → Consumer → Kafka (bus-delays) → Dashboard

## Tech Stack
- Apache Kafka
- Azure Event Hubs
- Python
- Streamlit

## How to Run
1. Start producer
2. Start consumer
3. Run dashboard
